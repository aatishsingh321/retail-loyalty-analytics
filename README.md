# 🛒 Retail Loyalty & Promotion Analytics

An end-to-end analytics project built for a hackathon that demonstrates how retail transaction data can be transformed into actionable business insights using Python and Streamlit.

---

## 📌 Project Overview

This project simulates a retail loyalty system where:
- Customers make purchases
- Promotions may or may not be applied
- Loyalty points are calculated
- Insights are generated through analysis and an interactive dashboard
